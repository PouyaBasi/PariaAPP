# Paria (iPhone web app)

Cute to-do app with pastel pink theme, white flowers, daily love notes, a History tab, Persian + Gregorian dates,
"Text Shayan" button (opens Messages), and a monthly paid-access lock (account + signed activation codes).

Read **SETUP.md** first, then **ADMIN_MANUAL.md**.

Files: index.html, app.js, styles.css, config.js (your settings), messages.js (love notes), admin.html (your approval page),
sw.js + manifest.webmanifest (installable app), icons/, scripts/send_push.js + .github/workflows/daily-push.yml (daily notification).
